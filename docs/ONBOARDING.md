## 可直接填写的项目资料

应用名称：项目追问官

应用介绍：面向准备 Java 后端实习面试的学生，提供围绕本人项目经历的文字训练。用户填写项目材料并核对事实，回答连续技术追问，查看带原回答与材料依据的复盘报告，补充说明后进行专项复测。反馈用于练习与自查，不承诺面试通过或获得录用。

收费场景：用户按次购买训练包。一个训练包包含一次完整项目深挖训练和一次与该训练关联的专项复测。付款确认后发放对应权益，用户可在订单页查看支付状态和剩余次数。系统故障按规则恢复训练或返还训练次数，训练次数返还不等于现金退款。

目标产品：AI 网页应用收款。应用通过网页提供服务，兼顾桌面与手机浏览器；真实手机支付链路尚未验证。

价格：由服务端 TRAINING_PRICE_CENTS 配置，新订单保存价格快照。模板默认 990 分（9.90 元），提交平台前须本人确认最终商品价格。不要将示例价格填为平台已批准价格。

技术说明（仅表单要求时填写）：React 与 TypeScript 前端，Spring Boot 服务端，数据库持久化订单与权益；服务端调用模型与支付宝 SDK，浏览器不持有模型密钥或支付私钥。仅验签通知或服务端交易查询确认付款，同步回跳不发放权益。

## 页面操作顺序

1. 在当前接入选择页选择「通过页面引导接入」，进入官方实际表单。若只是展示文档，继续使用页面给出的控制台或开通入口；不猜隐藏菜单或链接。
2. 登录、扫码、验证码、身份验证由本人完成。表单出现后可使用上面的应用名称、介绍和收费场景。
3. 若要求网站网址、资质或截图，先核对具体字段，不填 localhost、不伪造资质、不提交真实用户材料。网站还未公开部署，网址项暂不具备提交条件。
4. 在协议签署或最终提交前，本人阅读完整条款并核对资料；代码测试通过不代表平台申请通过。
5. 平台返回实际应用和配置后，按 PAYMENT.md 完成对应环境配置，再在独立数据库创建新订单进行沙箱验收。不得混用沙箱及生产账号、密钥或订单。
