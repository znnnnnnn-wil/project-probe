- `GET /api/trainings?summary=true` 返回训练摘要，包含状态、进度、项目名称及复测入口，不包含问答、材料及报告原文。工作台和项目编辑页使用摘要；原列表接口和详情接口保留兼容行为。
- 新生成的历史上下文使用一份 `historyTurns`，逐轮元数据仅保留问题 ID；模型提问输入使用明确字段清单，并过滤旧快照中重复的逐轮问答及内部操作状态。未批量改写历史数据库记录。
- 训练页轮询改为每次读取结束后延迟安排下一次；提交前取消旧读取，通过请求序号拒绝过期响应，离页取消读取及后续导航。提交后的刷新失败不再覆盖原操作错误。
- 全局加载状态改为请求计数，避免多个操作中某一个提前结束时错误解除忙碌状态。

## 第二批：剩余优化已落地

- 训练记录新增 `/api/training-page`，默认每页20条，最多100条，支持账号内项目/历史键筛选。展开记录后才读取该轮完整问答，保留原问答原文；兼容旧列表接口。
- 工作台通过 `/api/training-overview` 获取准确统计、待继续训练及每项目最近记录，不再下载全部已完成历史正文。项目列表和权益信息也使用摘要模式；项目编辑页在服务端按项目筛选训练。订单页批量装配状态，移除逐单查询。
- 列表与分页组装移至 `TrainingCatalog`，分页响应使用 `ListPage`，前端明确区分 `ProjectSummary`、`TrainingSummary` 和详情类型。分页中的复测关联可查询本页以外的子训练，避免分页导致复测入口错误。
- 历史索引补齐移出训练领取事务，每批最多25条独立提交，减少持有用户锁的时间；索引写入不再逐题先执行 COUNT。保留原始训练 body，不重写旧回答。
- 支付查询、关单和退款共用 `PaymentLease`：唯一token、到期检查、带token释放；结果写入在用户→订单的固定加锁顺序下校验所有权。旧执行者不能清除新租约或覆盖新结果；服务端不向浏览器返回租约token。
- 简历解析在文件解析前执行账号限额及并发保护：每账号24小时最多60次解析尝试，解析/识别服务有单实例并发上限。重复识别仍可命中缓存且不消耗模型识别次数；解析额度与模型额度分开。
- 文字模型增加单实例并发上限，默认4，使用 `MODEL_MAX_CONCURRENT_CALLS` 配置，允许1–32。繁忙或中断时保留既有恢复和返还机制，不切换模型。
- 文字模型和ASR使用 `BoundedBody` 在接收过程中限制响应字节数，超限取消订阅；保留原有字符数验证。普通请求增加实际读取字节限制，不再只依赖 Content-Length；错误JSON/参数返回400，超大请求返回413。
- 每个请求生成服务端 `X-Request-ID`，意外异常仅记录异常类型和代码位置，不记录异常消息、材料、密钥或第三方正文。前端 `ApiError` 保留请求ID，便于关联排查。
- 登录限流表增加容量上限及定期过期清理；过期登录会话定期清理。调度池设置为3个线程，减少慢支付补偿阻塞清理任务的情况。V10增加会话、列表、复测关联及支付账户查询索引。
- 前端按首页/登录、编辑、历史、训练、报告、订单及共享组件拆分，并按页面动态加载。新增页面错误边界和共享读取生命周期钩子，避免读取及轮询响应在离页后覆盖状态、导航或报错；迟到的创建训练结果也不会抢回页面。订单轮询改为串行调度，隐藏页面降低频率。
- 继续精简模型输入：当前轮、父轮和历史引用相同问题ID时只发送一次历史问答。内部操作状态、错误和私人复盘任务不会作为提问上下文发送。
